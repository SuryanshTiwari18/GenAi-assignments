# SVM, Trees, Ensembles, Validation & Unsupervised Learning Assignment

## Description
This assignment demonstrates the implementation of advanced machine learning algorithms including Support Vector Machines (SVM), Decision Trees, Model Validation, Cross-Validation, Ensemble Learning techniques, and Random Forest using the Retail Sales Dataset.

## Dataset Used
Retail Sales Dataset (Kaggle)

## Tasks Covered

- Task 1: Support Vector Machine (SVM)
- Task 2: Decision Tree Classifier
- Task 3: Train, Validation & Test Split
- Task 4: K-Fold Cross Validation
- Task 5: Bagging vs Boosting
- Task 6: Random Forest Classifier

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run

1. Open the project folder in VS Code.
2. Activate the virtual environment.
3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

4. Place the `retail_sales_dataset.csv` file in the project folder.
5. Open `assignment16.ipynb`.
6. Run all notebook cells sequentially.

## Learning Outcomes

After completing this assignment, you will be able to:

- Train and compare SVM models with Linear and RBF kernels.
- Build and visualize Decision Tree classifiers.
- Understand underfitting and overfitting using Decision Trees.
- Perform Train-Validation-Test splitting.
- Apply K-Fold Cross Validation.
- Compare Bagging and Boosting ensemble techniques.
- Train and evaluate a Random Forest classifier.
- Interpret feature importance in ensemble models.
