# Core Algorithms, Metrics & Model Behavior Assignment

## Description
This assignment demonstrates the implementation of fundamental Machine Learning algorithms for both regression and classification using the Retail Sales Dataset. It also covers model evaluation metrics, model behavior analysis, and the concepts of bias, variance, overfitting, and underfitting.

## Dataset Used
Retail Sales Dataset (Kaggle)

## Tasks Covered

- Task 1: Linear Regression
- Task 2: Regression Evaluation Metrics (MAE, MSE, RMSE)
- Task 3: Logistic Regression
- Task 4: Naive Bayes Classifier
- Task 5: K-Nearest Neighbors (KNN)
- Task 6: Classification Evaluation Metrics
- Task 7: Overfitting & Underfitting
- Task 8: Bias & Variance (Conceptual)

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## How to Run

1. Open the project folder in VS Code.
2. Activate the virtual environment.
3. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib scikit-learn
   ```
4. Place the `retail_sales_dataset.csv` file in the project folder.
5. Open `assignment15.ipynb`.
6. Run all cells sequentially.

## Learning Outcomes

After completing this assignment, you will be able to:

- Build and evaluate a Linear Regression model.
- Train and compare Logistic Regression, Naive Bayes, and KNN classifiers.
- Calculate and interpret regression and classification metrics.
- Understand the effects of overfitting and underfitting.
- Explain the concepts of bias and variance in machine learning.
